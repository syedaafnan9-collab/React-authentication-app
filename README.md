# React Authentication App

A responsive authentication interface built with React. This project focuses on creating a clean and user-friendly login and signup experience.

## Features

- Login and signup forms
- Show/hide password functionality
- Form input handling using React state
- Responsive user interface
- Smooth animations using Framer Motion
- Styled with Tailwind CSS

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Framer Motion
- Vite

## Getting Started

1. Clone this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## Purpose

This project was built to practice React components, state management, form handling, and responsive UI development.
